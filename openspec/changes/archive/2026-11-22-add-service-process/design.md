## Decisions
Use a small strict named-argument parser without a CLI dependency. Require --model, --version, --digest and --listen; default --workers=2 and --queue=16. Only literal loopback SocketAddr values are accepted; port zero is supported. Reject unknown/duplicate flags, missing/blank values and zero capacities. Digest remains caller-supplied opaque metadata, as in ModelBundle.
Load before creating the runtime or binding. Syntactically valid JSON uses load_json; other text uses load_yaml. Register through CubeService for structural/semantic validation. Create a current-thread Tokio runtime and use existing dedicated compilation workers. Bind and print `listening <actual-address>` only after registration and shutdown-signal setup. Host the generated Tonic server and await Ctrl-C for graceful shutdown. stdout contains readiness only; diagnostics use stderr and exit failure.
Alternatives: a general config/daemon adds deployment decisions; starting Doris spans an entire dialect matrix. The local executable gives a bounded usable B0 slice first. Remote hosting remains available through the library.
## Verification
Real child process and generated TCP client exercise all three RPCs and version selection; Unix SIGINT checks clean exit. Subprocess failures cover malformed arguments, invalid models and bind conflicts. Child cleanup is bounded. No new snapshots. Run fast/strict, full CI, real Docker smoke and different-vendor review before Ready.
