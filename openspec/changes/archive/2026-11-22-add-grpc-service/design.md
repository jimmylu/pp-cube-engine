## Decisions
Tonic/prost generates the ppcube.engine.v1 protocol. Match the public design field numbers: Compile oneof success/failure; parameters are ordered JSON scalar strings so text, boolean, number and null remain distinguishable. Output columns retain alias/member/type and optional granularity; used_tables are unique physical identifier paths joined with dots. Fingerprint is raw bytes. GetMeta uses serde JSON on public DTOs. ValidateModel accepts UTF-8 YAML or JSON (valid JSON is routed to the JSON validator to preserve surrogate-pair escapes) and returns located structured issues; invalid encoding yields InvalidArgument. Validation and metadata run on spawn_blocking; compilation uses the existing fixed CompilePool. Busy maps to ResourceExhausted, unavailable worker to Unavailable, compile errors to the declared failure class, unknown version to NotFound. Malformed query/security JSON returns InvalidArgument without SQL. Dialect accepts presto/doris/druid; only Presto is currently enabled and other recognized dialects return unsupported. The host is trusted to supply security filters; transport is for a trusted boundary, not an authenticated public endpoint.

GrpcService retains Arc<CubeService> and an owned CompilePool. The host constructs the service with explicit positive worker/queue capacities and registers versions beforehand. Generated CubeEngineServer can be mounted on an existing Tonic server with host-owned listener/shutdown. No default network bind is introduced. Compiler cancellation remains the pool's documented noncancelling behavior.

Sources: https://docs.rs/tonic-prost-build/0.14.9/tonic_prost_build/ and https://docs.rs/tonic/0.14.9/tonic/transport/struct.Server.html. Vendored protoc binaries avoid a CI system dependency. Tests use real TCP and generated client, with a current-thread runtime, comparing full wire fields, all operations, metadata privacy, unavailable versions, invalid inputs and preserved security restrictions. Final CI, real Docker smoke and cross-vendor review are required.
